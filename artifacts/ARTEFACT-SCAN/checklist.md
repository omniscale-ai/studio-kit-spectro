# ARTEFACT-SCAN — Review Checklist

- [ ] Was detection run across the series rather than per measurement?
- [ ] Is the contaminated region derived from the data, not hard-coded?
- [ ] For each contamination: is there evidence the points are *wrong*, not
      merely extreme?
- [ ] Are plausible-but-wrong contaminants considered, not just impossible ones?
- [ ] Is notch-vs-truncate justified by a score against an independent target?
- [ ] If truncating: is what else lives in the discarded range stated?
- [ ] Do the removal counts add up, each attributed to a cause?
- [ ] Is the Attestation filled with a reproducible invocation?
